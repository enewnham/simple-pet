# VADER lexicon

`vader_lexicon.txt` comes from the [NLTK data package](https://github.com/nltk/nltk_data/blob/gh-pages/packages/sentiment/vader_lexicon.zip).
The bundled copy supports offline sentiment scoring. [VADER-LICENSE.txt](VADER-LICENSE.txt)
contains the upstream MIT license.

Reference: Hutto, C.J. and Gilbert, E.E. (2014). VADER: A Parsimonious Rule-based Model
for Sentiment Analysis of Social Media Text. ICWSM-14.
